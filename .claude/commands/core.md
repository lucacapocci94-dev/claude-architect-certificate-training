---
description: "Start (or resume) the Core Concepts track."
allowed-tools: ["Bash(python3:*)"]
---

```bash
python3 .claude/bin/state.py set-current --track core-concepts
python3 .claude/bin/state.py next
```

Core Concepts has nine micro-lessons: rules & memory, slash commands, skills, hooks, permissions, subagents, plan mode, context window, MCP. Confirm the student is ready, then launch the first uncompleted lesson.
